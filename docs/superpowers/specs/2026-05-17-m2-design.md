# Milestone 2: Data Accuracy, Map Style & Historical Place Names — Design Spec

**Date:** 2026-05-17
**Status:** Approved, pending implementation plan
**Approach:** Infrastructure-first (Approach A)
**Data strategy:** Hybrid free datasets (cShapes + AWMC + OpenHistoricalMap + manual traces)

---

## Goal

Fix the data foundation before global expansion. M3 adds hundreds of entities worldwide — this milestone ensures the pipeline, schema, map style, data quality, and GIS foundations are production-grade before that work begins.

**M2 does NOT include:** vector tiles (M7), entity intelligence (M5), full events layer (M4), authentication (M8), animation interpolation, AI systems.

## Data Pipeline

### Existing path (13 entities — quality fix)
```
data/raw/political/<entity>/phase-N.geojson   ← replace rectangles with accurate traces
packages/data/entities/<entity>.yml           ← add source + confidence fields
→ ingest.py (logic unchanged)
→ PostGIS territories with all new columns populated
```

### New path (shapefile/external import)
```
data/sources/<source-name>/                   ← raw downloaded files (gitignored)
→ packages/data/importer.py                   ← new generic importer
    • reads shapefile (fiona) OR GeoJSON
    • maps source fields → entity/territory schema via source YAML
    • normalizes + simplifies geometry (reuses normalize.py)
    • bulk upserts via loader.py
→ PostGIS
```

### New files
- `packages/data/importer.py` — generic shapefile/GeoJSON importer, source-aware
- `packages/data/sources/cshapes.yml` — field mappings for cShapes dataset
- `packages/data/sources/awmc.yml` — field mappings for AWMC data
- `packages/data/fetch_sources.py` — CLI to download + checksum-verify source files
- `packages/data/place_names_loader.py` — loads historical city data
- `packages/data/rivers_loader.py` — loads river LineString GeoJSON into rivers table
- `data/sources/` — raw datasets (gitignored)
- `data/raw/place_names/ancient_cities.csv` — ~300 key historical cities
- `data/raw/physical/rivers.geojson` — major historical rivers (Nile, Tigris, Euphrates, Indus, Yellow River, Danube, Tiber, Rhine, Ganges)

## Database Schema — Migration `0002_m2_data_quality.py`

### Add to `territories`:
```sql
-- Source provenance
ALTER TABLE territories ADD COLUMN source_name    TEXT;
ALTER TABLE territories ADD COLUMN source_url     TEXT;
ALTER TABLE territories ADD COLUMN source_license TEXT;
ALTER TABLE territories ADD COLUMN data_version   TEXT;

-- Historical confidence
ALTER TABLE territories ADD COLUMN confidence_type  VARCHAR(20) DEFAULT 'approximate';
  -- values: 'exact' | 'approximate' | 'inferred' | 'disputed'
ALTER TABLE territories ADD COLUMN confidence_score FLOAT DEFAULT 0.5;
  -- 0.0 = completely uncertain, 1.0 = exact known boundary

-- Rendering metadata
ALTER TABLE territories ADD COLUMN resolution_km SMALLINT;
  -- approximate accuracy of boundary geometry in km
ALTER TABLE territories ADD COLUMN importance    SMALLINT DEFAULT 5;
  -- 1-10: controls rendering priority at low zoom levels
ALTER TABLE territories ADD COLUMN map_modes     TEXT[] DEFAULT '{political}';
  -- which map modes this territory appears in
  -- values: 'political' | 'physical' | 'trade' | 'religion' | 'migration' | 'military'
```

### New table: `data_sources`
```sql
CREATE TABLE data_sources (
  id           UUID PRIMARY KEY,
  slug         VARCHAR(100) UNIQUE NOT NULL,
  name         TEXT NOT NULL,
  url          TEXT,
  license      TEXT,
  description  TEXT,
  year_min     INT,
  year_max     INT,
  coverage     TEXT   -- "global", "europe", "mediterranean"
);
```

### New table: `place_names`
```sql
CREATE TABLE place_names (
  id             UUID PRIMARY KEY,
  name           TEXT NOT NULL,         -- "Constantinople"
  name_modern    TEXT,                  -- "Istanbul"
  type           VARCHAR(50),           -- city, settlement, region, sea, mountain, river
  geom           GEOMETRY(POINT,4326) NOT NULL,
  year_start     INT NOT NULL,
  year_end       INT,                   -- NULL = still exists today
  min_zoom       SMALLINT DEFAULT 3,
  source_name    TEXT,
  importance     SMALLINT DEFAULT 5,   -- 1-10, global historical significance
  label_priority SMALLINT DEFAULT 5,   -- 1-10, collision resolution order (higher = rendered first)
  map_modes      TEXT[] DEFAULT '{political}'
);

CREATE INDEX place_names_year_idx ON place_names(year_start, year_end);
CREATE INDEX place_names_geom_idx ON place_names USING GIST(geom);
```

### New table: `rivers`
```sql
CREATE TABLE rivers (
  id         UUID PRIMARY KEY,
  name       TEXT NOT NULL,             -- "Nile"
  name_alt   TEXT,                      -- "Neilos" (ancient name)
  geom       GEOMETRY(LINESTRING,4326) NOT NULL,
  year_start INT,                       -- NULL = predates all records
  year_end   INT,                       -- NULL = still exists
  importance SMALLINT DEFAULT 5,        -- 1-10, controls rendering at zoom levels
  source_name TEXT,
  map_modes  TEXT[] DEFAULT '{political,physical,trade,migration,military}'
);

CREATE INDEX rivers_geom_idx ON rivers USING GIST(geom);
```

### New table: `entity_capitals`
Tracks which city was the capital of an entity during a given period.
```sql
CREATE TABLE entity_capitals (
  id            UUID PRIMARY KEY,
  entity_id     UUID NOT NULL REFERENCES entities(id) ON DELETE CASCADE,
  place_name_id UUID NOT NULL REFERENCES place_names(id) ON DELETE CASCADE,
  year_start    INT NOT NULL,
  year_end      INT,                   -- NULL = until entity ends
  capital_type  VARCHAR(20) DEFAULT 'primary'
                                       -- 'primary' | 'co-capital' | 'regional'
);

CREATE INDEX entity_capitals_entity_idx ON entity_capitals(entity_id);
CREATE INDEX entity_capitals_year_idx   ON entity_capitals(year_start, year_end);
```

### New table: `regions`
Non-political geographic/cultural regions (Gaul, Mesopotamia, Anatolia, Germania). Persist across political changes. Schema only in M2 — no frontend rendering yet.
```sql
CREATE TABLE regions (
  id          UUID PRIMARY KEY,
  name        TEXT NOT NULL,           -- "Mesopotamia"
  type        VARCHAR(30),             -- 'geographic' | 'cultural' | 'administrative'
  geom        GEOMETRY(MULTIPOLYGON,4326),
  year_start  INT,                     -- NULL = predates records
  year_end    INT,                     -- NULL = still used
  description TEXT,
  source_name TEXT,
  map_modes   TEXT[] DEFAULT '{physical,cultural}'
);

CREATE INDEX regions_geom_idx ON regions USING GIST(geom);
```

### New table: `timeline_notes`
Lightweight annotation system. Global context markers shown while sliding through time. Not a full events system.
```sql
CREATE TABLE timeline_notes (
  id        UUID PRIMARY KEY,
  year      INT NOT NULL,              -- exact year
  note      TEXT NOT NULL,             -- "Fall of Western Roman Empire"
  entity_id UUID REFERENCES entities(id) ON DELETE SET NULL,
  region    TEXT,                      -- optional geographic scoping, e.g. "Western Europe"
  importance SMALLINT DEFAULT 5        -- 1-10, controls whether shown at current zoom/view
);

CREATE INDEX timeline_notes_year_idx ON timeline_notes(year);
```

## Map Style Overhaul

### Removed from base tiles:
- Country borders and boundary lines
- Country name labels
- State/province borders and labels
- Region political labels
- Disputed territory markers

### Kept in base tiles:
- Terrain/elevation shading
- Coastlines and ocean fill
- Major rivers and lakes (base style only — our `rivers` layer renders on top)
- Mountain range labels (physical geography only)
- Ocean and sea labels
- City dot markers (no names — replaced by our place_names layer)

### Implementation:
- Base: OpenFreemap "Positron" style JSON downloaded locally
- Strip political layers via `scripts/build-map-style.ts`
- Output: `apps/web/public/map-style/historical.json`
- MapLibre loads local `historical.json` instead of remote URL
- Layer render order (bottom to top): base style → rivers → regions (M3+) → territories → place_names

### Historical place names layer (frontend):
New MapLibre symbol layer `historical-place-names`:
- Hits `/api/v1/place-names?year=&bbox=&zoom=` on year change
- Filtered by `min_zoom`, `importance`, `label_priority`
- Shows historical city names ("Constantinople") not modern ("Istanbul")
- Debounced same as territory layer
- MapLibre collision detection prevents label overlap

### Historical rivers layer (frontend):
New MapLibre line layer `historical-rivers`:
- Loaded once at map init from `/api/v1/rivers` (static — no year param)
- Rendered below territory polygons
- Styled as thin blue lines, low opacity
- Does not re-fetch on year change (rivers are geologically stable across human history)

## API

### `GET /api/v1/place-names`
```
Query params:
  year     int   required
  min_x    float (default -180)
  min_y    float (default -90)
  max_x    float (default 180)
  max_y    float (default 90)
  zoom     int   (default 4)

Response: GeoJSON FeatureCollection
  features[].geometry         Point
  features[].properties:
    name           string     "Constantinople"
    name_modern    string     "Istanbul"
    type           string     "city"
    importance     int        1-10
    label_priority int        1-10
```
Cached in Redis: `place_names:{year}:{zoom}:{tile_x}:{tile_y}`

### `GET /api/v1/rivers`
```
No required params.

Response: GeoJSON FeatureCollection
  features[].geometry         LineString
  features[].properties:
    name        string        "Nile"
    name_alt    string        "Neilos"
    importance  int           1-10
```
Cached in Redis: `rivers:all` (static, long TTL — 24h)

### `GET /api/v1/sources`
```
No params.
Response: JSON array of data_sources rows.
```
No Redis cache — static data, loaded once at app start.

### `GET /api/v1/world/state` — additions only:
Add to each feature's properties:
- `source_name: string` — per-territory attribution in EntityPanel
- `confidence_type: string` — "exact" | "approximate" | "inferred" | "disputed"
- `importance: int` — for future zoom-level filtering

## Map Mode Architecture (Foundation Only)

M2 establishes mode-awareness in the schema. Full mode-switching UI is M4+. In M2:

- All new tables include a `map_modes TEXT[]` column
- Default value `'{political}'` for political territories
- Rivers default to all modes: `'{political,physical,trade,migration,military}'`
- API filters by mode are NOT implemented yet — column exists for M4
- No frontend mode switcher in M2

This ensures no schema migration is required when map modes ship in M4.

Planned modes (for reference):
- `political` — territory borders (current)
- `physical` — rivers, terrain, natural regions
- `trade` — trade routes, economic zones
- `religion` — religious boundaries, pilgrimage routes
- `migration` — population movement flows
- `military` — campaigns, battle markers, fortification lines
